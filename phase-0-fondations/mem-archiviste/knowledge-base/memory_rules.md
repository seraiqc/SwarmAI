# Règles MEM

1. Toute fiche doit avoir un `id` unique.
2. Toute modification doit incrémenter `version`.
3. Toute fiche doit avoir `updated_at`.
4. Aucun agent ne doit inventer un personnage déjà existant avec un autre nom sans nouvelle fiche.
5. Les contradictions doivent être corrigées dans la fiche source, pas dans des copies locales.
6. Les requêtes inter-agents doivent passer par l'API MEM.
7. Les tags doivent suivre `tags.md`.
8. Les résumés doivent être courts, mais le corps peut être détaillé.
