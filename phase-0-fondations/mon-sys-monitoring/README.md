# MON-SYS — Agent Monitoring Système

MON-SYS surveille la santé du Swarm en temps réel.

## Mission
- Vérifier l’uptime
- Suivre la performance
- Surveiller les coûts API
- Détecter les erreurs agents
- Déclencher des alertes de dégradation

## Dossiers
- prometheus/ : métriques système
- grafana/ : dashboards visuels
- sentry/ : tracking des erreurs
