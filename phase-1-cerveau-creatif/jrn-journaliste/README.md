# JRN — Agent Journaliste

JRN écrit un journal numérique quotidien à partir de différentes sources d’information.

## Mission
- Collecter des nouvelles depuis plusieurs sources
- Trier les sujets utiles
- Rédiger un journal clair
- Préparer des éditions archivées

## Dossiers
- sources/ : flux RSS et APIs
- pipeline/ : collecte, tri, rédaction
- editions/ : sorties finales du journal
